O que é o Teorema CAP?

O Teorema CAP (também conhecido como Teorema de Brewer) afirma que é impossível para um sistema de armazenamento de dados distribuído garantir simultaneamente mais de duas das três propriedades seguintes:

  • Consistência (Consistency): Todos os nós veem os mesmos dados ao mesmo tempo.
  • Disponibilidade (Availability): Toda requisição recebe uma resposta sobre seu sucesso ou falha.
  • Tolerância a Partição (Partition tolerance): O sistema continua a funcionar apesar de perdas de mensagens ou falhas em parte do sistema.
