Calculus II

Resumo Aula 05 - Integrais

A integral definida de f(x) de a até b é a área sob a curva. Teorema Fundamental do Cálculo: ∫ f(x)dx = F(b) - F(a). Lembrar das regras de substituição e integração por partes. Para integrais trigonométricas, usar identidades de ângulo duplo para simplificar sen²(x) e cos²(x).

Data Structures

Árvores Binárias de Busca

Propriedade fundamental: para todo nó, a subárvore esquerda contém apenas valores menores, e a direita apenas valores maiores. Operações de busca, inserção e deleção têm complexidade O(h), onde h é a altura da árvore. Necessidade de balanceamento (AVL, Red-Black) para evitar O(n) no pior caso.

Linear Algebra

Autovalores e Autovetores

Equação característica: det(A - λI) = 0. Os valores de λ são os autovalores. Substituindo λ de volta em (A - λI)v = 0, encontramos os autovetores v correspondentes. Diagonalização de matrizes é possível se e somente se a matriz possuir n autovetores linearmente independentes.
