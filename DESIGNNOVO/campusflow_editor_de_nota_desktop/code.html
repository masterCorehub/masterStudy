A derivada parcial de uma função de várias variáveis é a sua derivada em relação a uma daquelas variáveis, mantendo as outras variáveis constantes. Isso é diferente da derivada total, na qual todas as variáveis podem variar.

Notação

Seja f(x, y) uma função de duas variáveis. A derivada parcial de f em relação a x é denotada por:

∂f / ∂x = lim (h → 0) [ f(x + h, y) - f(x, y) ] / h

Pontos Principais

  • Ao calcular ∂f/∂x, trate y como uma constante.
  • Ao calcular ∂f/∂y, trate x como uma constante.
  • As regras normais de derivação (produto, quociente, cadeia) aplicam-se normalmente.

*Nota: Lembre-se de revisar o Teorema de Clairaut sobre a igualdade das derivadas parciais mistas para a próxima aula.*
